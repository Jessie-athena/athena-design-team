API / Props

PropTypeDefault說明
dataSourceSettingsDataSourceSettings—核心設定物件，包含 dataSource、rows、columns、values、filters
dataSourceSettings.dataSourceObject[] | DataManager—原始資料
dataSourceSettings.rowsFieldOptions[][]列維度欄位（每項含 name）
dataSourceSettings.columnsFieldOptions[][]欄維度欄位
dataSourceSettings.valuesFieldOptions[][]值欄位（含 type: 'Sum' 等聚合）
showFieldListbooleanfalse顯示右側欄位清單面板
expandAllbooleanfalse預設展開所有維度節點
enableValueSortingbooleanfalse允許點擊值欄標頭排序

⚠️ 所有維度（rows / columns / values / filters）皆內嵌於 dataSourceSettings 物件，不是頂層 prop。
