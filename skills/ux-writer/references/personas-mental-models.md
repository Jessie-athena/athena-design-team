# 使用者角色與心智模型

> 寫任一段文案前，先確認「這是寫給誰看、他正在做什麼、他怎麼想這件事」。
> 同一個功能、同一個錯誤，寫給不同角色，**用詞、資訊順序、要強調的點都會不同**——這份檔幫你對齊讀者心智，而不是只套句型。
> 每個角色看：**是誰／在什麼任務流程 · 心智模型（怎麼想）· 在意 / 焦慮 · 慣用詞彙 · 文案啟示**。

---

## 跨角色共通心智（ERP 單據世界）

德安 ERP 使用者整天在處理「單據」，有兩個共通心智，寫單據相關文案時都適用：

### 1. 單據掃描順序（資訊該怎麼排）
專業使用者拿到一張單，視線與決策順序是：
**單號（這是哪張）→ 決策區（對象 → 類型 → 經辦 → 日期）→ 隔離帶入（公司別等）**

- 文案、欄位 label、摘要列的資訊先後**對齊此順序**，使用者才不用回頭找。
- 例：單據摘要寫「採購單 PO-2026-001｜供應商 大豐｜採購類型 進貨｜經辦 王小明｜2026/06/08」，而非把公司別、建立時間放最前面。
- **排或審 header／List 完整欄序**（三區模型 vs 雙列模型、公司別落點、財務無經辦欄等）→ 見 `erp-field-order.md`，那是欄序的權威規則。

### 2. 可逆心智（這張單還能不能反悔）
- **草稿**＝還沒成立 → 可直接刪除，使用者預期「丟掉就沒了」。
- **已提交 / 已核准**＝已成立、有軌跡 → 只能**作廢**留痕，不能物理刪除。
- 文案要對齊此預期：草稿用「刪除」、已成立的單用「作廢」，並說明「作廢會留紀錄、不可復原」。

## ERP 角色

### 會計 / 財務
- **任務流程**：審單 → 產生傳票 → 過帳 → 對帳 / 沖銷 → 期末結轉。
- **心智模型**：腦中是一組「借貸必須平衡、每筆都要能追溯到傳票」的帳務邏輯。看一張單先想「這會變成哪張傳票、金額對不對得起來」。
- **在意 / 焦慮**：金額平不平、傳票有沒有正確產生、能不能追溯來源、期別有沒有結錯。
- **慣用詞彙**：傳票、過帳、沖銷 / 沖帳、分攤、借貸、期別、未過帳。
- **文案啟示**：金額與傳票的關係要**透明**——摘要把「金額等式 + 已產生傳票」講清楚；阻擋訊息點出帳務原因（如「無法結轉：本期尚有未過帳單據」）讓會計知道去處理什麼。

### 倉管
- **任務流程**：收貨入庫 → 領料 / 出庫 → 調撥 → 盤點 → 結轉。
- **心智模型**：腦中是「實際庫存 vs 帳面數量」的對應，每個動作都會動到某地點的數量。
- **在意 / 焦慮**：料帳是否一致、庫存會不會變負、盤盈虧差異、這個動作會連動哪些庫存。
- **慣用詞彙**：入庫、領料、出庫、調撥、盤點、盤盈 / 盤虧、地點、庫存連動。
- **文案啟示**：點出**庫存連動後果**（如「作廢將還原本單已扣減的庫存」）；數量相關阻擋要具體（哪個料、哪個地點、差多少）。

### 採購
- **任務流程**：請購 → 採購 → 收貨 → 退貨；對廠商、交期。
- **心智模型**：以「一條從請購到收貨的鏈」在想事情，怕斷鏈、怕重複、怕漏。
- **在意 / 焦慮**：有沒有重複下單、交期會不會延、收貨對不對得上採購、退貨流程。
- **慣用詞彙**：請購單、採購單、收貨、退貨、供應商、交期。
- **文案啟示**：關聯單據關係要清楚（這張採購單來自哪張請購單）；阻擋訊息講清是鏈上哪一環卡住。

### 業務
- **任務流程**：報價 → 銷貨訂單 → 出貨 → 折讓 → 收款；對客戶、客戶分級。
- **心智模型**：以「服務客戶、把單順利出掉並收到錢」在想事情。
- **在意 / 焦慮**：會不會漏出貨、價格 / 折讓對不對、客戶分級對應的條件、收款狀態。
- **慣用詞彙**：報價單、銷貨訂單、出貨、折讓、客戶分級、收款。
- **文案啟示**：以客戶與訂單進度為敘事主軸；金額 / 折讓相關提示要讓業務一眼看出對客戶的影響。

## 餐飲（seed）

> 內容為初步側寫，待累積實際案例補強。

### 店員（iPad POS）
- **任務流程**：點餐 → 送單 → 結帳 → 列印 / 重印發票；現場面對客人。
- **心智模型**：站著、單手、邊招呼客人邊操作，要「快、看一眼就懂、不要擋住下一步」。
- **在意 / 焦慮**：會不會點錯、結帳快不快、發票對不對、彈窗會不會卡住出餐節奏。
- **慣用詞彙**：點餐、送單、結帳、發票、重印、退點。
- **文案啟示**：句式短、用問句（「是否重印發票？」）、即時回饋用 Toast 不擋手；正向動作放右側（見 SKILL.md 各垂直慣例）。

### 店長
- **任務流程**：日結、報表、權限與設定。
- **在意 / 焦慮**：當日營收對不對、權限給對人、報表能不能交代。
- **文案啟示**：日結 / 報表類偏資訊密度高、可追溯；權限訊息講清誰能做什麼。

- **在意 / 焦慮**：房型房價有沒有空、訂房衝突、候補順位。
- **慣用詞彙（待確認）**：房型、房價、訂房、候補、住房日期。
