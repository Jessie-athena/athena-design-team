# 德安 ERP 單據文案慣例

> 處理 **ERP 模組**（`docs/notion/` 規格、prototype、Vue 介面）時套用本檔。
> 這些慣例是從既有德安 ERP 文案歸納的事實標準，照著走才能跨單據一致。
> 餐飲（POS）、飯店（PMS/CRS）有各自慣例，勿把本檔的單據狀態機與括號規則直接套到非單據介面。

## 1. 狀態機詞彙（強制，勿自創）

單據狀態固定四個 + 一個獨立分支：

| 狀態 key | 顯示文字 |
|---|---|
| `draft` | 草稿 |
| `submitted` | 已提交 |
| `approved` | 已核准 |
| `voided` | 已作廢（獨立分支） |

動作按鈕用語：**提交**（draft→submitted）、**核准**（submitted→approved）、**解核**（approved→submitted）、**作廢**。其他常見動作：**產生傳票**、**沖銷**、**複製**、**列印**、**匯入**、**匯出**、**儲存變更**、**查詢**、**清除篩選**。

- 「已產生傳票」是 **chip**，由 `move_id` 是否存在判斷，**不是**獨立狀態，勿放進狀態機。
- 偏離此命名（例如改叫「送審／審核／取消審核」）必須在交付訊息註明理由。

## 2. 括號慣例（最容易寫錯，務必分清）

德安 ERP 文案用三種括號表達三種語意：

| 括號 | 語意 | 範例 |
|---|---|---|
| `〔…〕` | 句中**可點擊的動作**（inline CTA） | 「請調整搜尋條件或〔清除篩選〕」 |
| `『…』` | **引用** UI 元素名／按鈕／動態值（本身不可點） | 「明細已移除，請按主表『儲存變更』完成寫入」、`『{name}』` |
| `「…」` | 引述**訊息／狀態文字本身** | 顯示「已產生傳票」 |

> 不要用 `[方括號]` 當 inline CTA（那是消費級寫法）。德安 ERP 句中動作一律 `〔〕`。
> 例外：彈窗按鈕列以 `[取消] [作廢]` 表示是可接受的版面示意，與句中 CTA 不同。

## 3. 固定句型

**驗證／阻擋類錯誤**（事務性）：`無法[動作]：[原因]`（冒號分隔；原因要具體、可行動）
```
無法刪除：已被歷史單據引用
無法刪除：選取項目皆已阻擋
無法刪除『{name}』，因該類別下仍有 N 個計量單位
無法結轉：本期尚有未過帳單據
```
> 系統／預期外錯誤（連線中斷、伺服器異常）改用同理安撫句型，見 SKILL.md「錯誤訊息按類型分工」。

**操作結果 Toast**：`已[動作] N 筆`（批次帶數量；單筆可省 N）
```
已刪除 N 筆草稿
已匯出 N 筆
已套用篩選條件 / 已重置篩選
已開啟新增表單
```

**破壞性確認**：`[後果說明]，是否繼續？`，CTA 用明確動詞
```
作廢後無法復原，是否繼續？           [取消] [作廢]
所選項目皆未被引用，刪除後無法復原。  [取消] [刪除]
```

**儲存提醒**（明細改動需回主表存檔）：
```
明細已更新，請按主表『儲存變更』完成寫入
請修正紅框欄位後再儲存
```

## 4. 單據領域術語（取代專案管理用語）

| 用語 | 說明 | 避免 |
|---|---|---|
| 單號 | 單據主鍵 | 不用「編號／ID」 |
| 明細 | 單據行項目 | 不用「項目／清單」 |
| 傳票 | 會計分錄（move） | 不用「分錄／憑證」 |
| 引用 | 被其他單據參照（故不可刪） | 不用「使用中／關聯」 |
| 篩選 | 列表查詢條件 | 不用「過濾器／filter」 |
| 沖銷 / 沖帳 | 帳款核銷 | 依模組既有用字 |
| 過帳 | 傳票入帳 | — |
| 結轉 | 期末結轉 | — |
| 阻擋 | 不符條件而被擋下 | — |
| 公司別 / 部門 | 組織維度 | — |

> 跨語系時，這些 ERP 單據術語目前以繁中為準；尚未建立日／越／簡中對照，需翻譯時請與 PM 確認產業慣用詞，勿自行直譯。一般 UI 詞彙（建立/刪除/儲存/篩選…）見 `Terminology.md` 五語對照表。

## 5. ERP Copy Doc 範本

維護一份 Copy Doc（可放 Notion），讓跨模組命名單一來源：

```markdown
# Athena ERP Copy Doc

## 狀態與動作（全模組共用，勿改）
草稿 / 已提交 / 已核准 / 已作廢
提交 / 核准 / 解核 / 作廢 / 產生傳票 / 沖銷 / 複製 / 列印 / 匯入 / 匯出

## 術語表
| 英文 | 中文 | 使用情境 | 避免 |
|------|------|---------|------|
| Document No | 單號 | 所有單據 | 不用「編號」 |
| Line | 明細 | 單據行 | 不用「項目」 |
| Voucher / Move | 傳票 | 會計分錄 | 不用「憑證」 |
| Reference | 引用 | 被參照不可刪 | 不用「使用中」 |
| Filter | 篩選 | 列表查詢 | 不用「過濾器」 |

## 數字與日期
- 「3 筆單據」（數字 + 空格 + 單位）
- 「2026/06/08」或「2026 年 6 月 8 日」（多語系格式見 Frameworks.md）
- 相對時間：「3 分鐘前」「昨天 14:30」
```
