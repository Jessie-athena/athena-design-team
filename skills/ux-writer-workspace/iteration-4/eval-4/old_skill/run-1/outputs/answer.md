# 採購單 Header 欄序審查

## 結論：順序不對，需調整

待審查順序：

```
公司別 → 採購單號 → 採購日期 → 供應商 → 採購人員
```

## 判斷依據

德安 ERP 單據的 header 欄序，須對齊**專業使用者的單據掃描 / 決策心智順序**（SKILL §2、personas §跨角色共通心智）：

```
單號（這是哪張）
 → 決策區（對象 → 類型 → 經辦 → 日期）
 → 公司別（組織維度，隔離帶入，放最末）
```

採購人員是「採購」角色，心智是「一條從請購到收貨的鏈」，下筆要讓他先確認「這是哪張單、對哪個供應商、誰經辦、什麼時候」，最後才是公司別這種隔離維度。把公司別放最前面會讓他每次都要先跳過組織欄位才看到真正要判斷的內容，違反掃描順序。

## 欄位對位

| 本單欄位 | 心智角色 | 應在位置 |
|---|---|---|
| 採購單號 | 單號（PK） | 第 1（首） |
| 供應商 | 對象 | 決策區 1 |
| 採購人員 | 經辦 | 決策區 2 |
| 採購日期 | 日期 | 決策區 3 |
| 公司別 | 組織維度 | 最末 |

> 註：決策區標準序為「對象 → 類型 → 經辦 → 日期」。本單未列「採購類型」欄位，故類型缺位，其餘欄位依序遞補；若實際單上有採購類型，應插在供應商與採購人員之間。

## 逐項問題

1. **公司別放在第 1 位 — 錯。** 公司別是隔離帶入的組織維度，應放最末，不該擋在單號前面。
2. **採購日期排在供應商、採購人員之前 — 錯。** 日期是決策區最後一項，應排在對象（供應商）、經辦（採購人員）之後。
3. **供應商（對象）排在採購人員（經辦）之後 — 順序相對正確，但兩者整體位置因前述錯位而需一併調整。** 對象應先於經辦。

## 修正後正確順序

```
採購單號 → 供應商 → 採購日期 → 採購人員 → 公司別
```

依「對象 → 類型 → 經辦 → 日期」展開決策區後：

```
採購單號 → 供應商 → 採購人員 → 採購日期 → 公司別
```

採購單號（單號）為首；供應商（對象）、採購人員（經辦）、採購日期（日期）為決策區，依對象 → 經辦 → 日期排列；公司別（組織維度）置於最末。
