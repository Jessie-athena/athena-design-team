# 採購單 Header 欄序審查

## 結論：不對，需修正

採購單屬**進銷存（PSI）模組家族**，套用**三區模型**（識別區 → 決策區 → 隔離區）。
採購單為單段設計，公司別應落在基本資訊**末欄**。

你提的順序：`公司別 → 採購單號 → 採購日期 → 供應商 → 採購人員`
與三區模型的骨幹有 4 處衝突，逐項列於下。

---

## 逐項問題

| # | 你的排法 | 問題 | 違反規則 |
|---|---|---|---|
| 1 | 公司別排**第 1 格** | 公司別屬「隔離／後台帶入欄」，不該擋決策動線，更不能佔首格 | 反例「PSI 單段卻把公司別塞前段」；公司別單段設計應在**末欄** |
| 2 | 採購單號排第 2 格 | 單號**永遠第 1 格、唯讀**（草稿顯「/」、取號後帶入） | 跨家族共通骨幹第 1 條；反例「單號非首格」 |
| 3 | 採購日期排在供應商**之前** | 決策動線應為 對象（供應商）→ 類型 → 經辦 → 日期；日期應在對象之後 | 決策區順序（對象 → … → 日期） |
| 4 | 採購人員（經辦）排在日期**之後** | 有經辦欄時，**經辦永遠排在日期前** | 共通骨幹第 2 條；反例「把經辦人排到日期後」 |

---

## 修正後的正確順序

```
採購單號 → 供應商 → 採購人員 → 採購日期 → 公司別
```

對應三區模型：

- **① 識別區（最前、固定）**：`採購單號`（第 1 格、唯讀，草稿顯「/」）
- **② 決策區（中段，照操作先決順序）**：`供應商`（對象）→ `採購人員`（經辦）→ `採購日期`（日期）
  - 此採購單若無「採購類型」欄則直接跳過，順序維持不變；若有，插在 供應商 與 採購人員 之間（對象 → 類型 → 經辦 → 日期）。
- **③ 隔離／後台區（最後、固定）**：`公司別`（單段設計 → 排基本資訊末欄）

> 與既有落地範例一致，例如驗收單：`驗收單號 → 採購單號 → 供應商 → 簽收人員 → 驗收日期 → …→ 公司別`，皆是「單號首格、對象→經辦→日期、公司別末欄」。

---

## 補充提醒

- 若採購單另有來源／關聯單據（如請購單號），依識別區規則排在**採購單號之後、供應商之前**。
- 明細（品號／數量／單價）與金額**不放 header**，置於 Tab block／Summary Card。
- 若後續把地點相關欄拆成獨立「地點資訊／公司資訊」段，則公司別改為**領銜該段首位**（而非末欄）；目前以單段設計判定為末欄。
