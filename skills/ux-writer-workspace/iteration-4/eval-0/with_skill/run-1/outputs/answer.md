# 成本調整單 —「基本資訊」Section Header 欄位順序

## 先判定模組家族

成本調整單屬於 **進銷存（PSI）／採購** 家族，header 為**單一序列、無拆段**設計。因此套用 **三區模型**（識別 → 決策 → 隔離），而非財務的雙列模型。

## 建議欄序

```
成本調整單號 → 地點 → 調整人員 → 調整日期 → 公司別
```

| 順序 | 欄位 | 所屬區 | 屬性 | 備註 |
|---|---|---|---|---|
| 1 | 成本調整單號 | ① 識別區 | 唯讀 | 草稿階段顯「/」，取號後帶入 |
| 2 | 地點 | ② 決策區（對象槽位） | 必填 | 調整成本的標的範圍，歸「對象」思考 |
| 3 | 調整人員 | ② 決策區（經辦） | 必填 | 經辦欄，排在日期前 |
| 4 | 調整日期 | ② 決策區（日期） | 必填 | 決策動線收尾 |
| 5 | 公司別 | ③ 隔離／後台區 | 唯讀／自動帶入 | 單段設計 → 落在基本資訊末欄 |

> 明細（品號／數量／調整前後成本／差額）與金額**不放 header**，移至 Tab block／Summary Card。

---

## 為什麼這樣排

### 1. 單號永遠第 1 格、唯讀（跨家族共通骨幹）
單號是這張單的身分，使用者掃單第一眼就是它。它非可操作欄（草稿顯「/」、取號後系統帶入），所以固定在最前、標唯讀。**反例提醒**：絕不可把單號搬到 header 末尾（PSI 曾誤排被 PM 糾正）。

### 2. 決策動線「對象 → 經辦 → 日期」對齊使用者掃描順序
中段照倉管／成本人員的實際決策先後排：
- **地點**＝這次要調整的標的範圍，屬「對象槽位」，使用者先決定「調哪裡」，所以排在經辦與日期前。
- **調整人員（經辦）排在調整日期前**——這是 PSI 的硬規則：有經辦欄時，經辦永遠在日期前，使用者先確認「誰在調」再看「哪天調」。
- 成本調整單沒有「單據類型」「稅別」「來源單號」等欄，依規則**缺的欄直接跳過、不硬補**，其餘欄維持既有相對位置。

### 3. 公司別落在末欄（單段設計的隔離區）
公司別是組織維度、唯讀自動帶入欄，不需使用者在決策時操作。三區模型把這類帶入欄集中到後段，避免擋住前面的決策輸入動線。

成本調整單是**單一段設計**（沒有拆出獨立的「地點資訊／公司資訊」段），所以公司別排在**基本資訊末欄**——這與請購單那種「拆出地點資訊段、由公司別領銜段首」的做法不同，差別只在有沒有獨立段，兩者都符合「公司別屬隔離帶入、不擋決策動線」的同一精神。

**反例提醒**：
- 不要把公司別塞進決策區中段（單段設計應在末欄）。
- 也不要照搬財務雙列模型把它放到後台列靠前——那是財務單據的規則，PSI 不適用。
