# 成本調整單（進銷存／採購）—「基本資訊」Section header 欄位順序

## 建議欄位順序

依德安 ERP 單據掃描順序（單號 → 決策區：對象 → 類型 → 經辦 → 日期 → 公司別）排，套到成本調整單為：

| 順序 | 欄位 | 區段 | 必填 | 說明 |
|---|---|---|---|---|
| 1 | 單號 | 識別 | 唯讀 | 單據主鍵，這是哪張單；新單顯示「新單」、儲存後帶單號 |
| 2 | 調整類型 | 決策區—類型 | 必填 | 成本調整無外部對象（非請購／採購對廠商），故由「類型」打頭：標明這張單在調什麼（如 進貨成本／結轉成本／人工差異）。先定類型，後面欄位的判讀基準才確立 |
| 3 | 調整標的 | 決策區—對象 | 必填 | 成本調整的對象是「料件／品項」而非廠商；緊接類型，讓使用者一眼確認調的是哪個料、哪個倉 |
| 4 | 經辦 | 決策區—經辦 | 必填 | 誰負責這張單；責任歸屬，預設帶當前使用者 |
| 5 | 調整日期 | 決策區—日期 | 必填 | 影響落在哪個期別／成本時點；會計關心結到哪一期，故緊接經辦、在公司別之前 |
| 6 | 備註 | 決策區—補述 | 選填 | 調整原因等自由說明；放決策區末尾，不打斷上方判讀主線 |
| 7 | 公司別 | 隔離帶入 | 必填／唯讀 | 組織維度，多由登入情境帶入、最少變動，置於最末作隔離欄，不佔據前段判讀注意力 |

> 若該模組成本調整需區分倉別／部門，倉別歸在「調整標的」同區（對象的延伸），部門與公司別同屬組織維度、緊鄰公司別放最末。

## 為什麼這樣排

### 1. 對齊使用者的掃描與決策順序（核心依據）
德安 ERP 專業使用者（此處為採購／倉管／會計）拿到一張單，視線與決策固定走：
**單號（這是哪張）→ 決策區（對象 → 類型 → 經辦 → 日期）→ 隔離帶入（公司別）**。
欄位 label 的先後對齊這個順序，使用者就不用回頭找、不用跳著讀。

### 2. 「類型」在成本調整單要提到「對象」前面
通用順序是「對象 → 類型」，但那是建立在**有外部交易對象**（如採購單對供應商）的單據上。成本調整單**沒有對外對象**——它調的是內部料件的成本，因此：
- 真正決定「這張單怎麼判讀」的第一決策是**調整類型**（在調進貨成本？結轉差異？人工？），類型一旦選定，後面要填什麼、調哪個標的的基準才成立。
- 故把「調整類型」提到決策區之首、「調整標的（料件）」緊隨其後。這仍是「先定判讀框架、再定具體對象」的同一心智，只是成本調整的判讀框架是類型而非對象。

### 3. 日期放決策區末、公司別之前
成本調整直接牽動**期別與成本時點**，會計／倉管在意「這筆調整結到哪一期、料帳是否一致」。日期是判讀這張單帳務落點的最後一個關鍵欄，所以收在決策區尾、但仍排在公司別之前。

### 4. 公司別固定壓尾（隔離帶入）
公司別是組織維度，通常由登入情境自動帶入、最少需要使用者主動判斷或變動。把它放最末，避免它佔據前段的判讀注意力——使用者掃單時先看「這張在調什麼、調哪個料、誰辦的、結哪期」，最後才確認組織歸屬。這也是既有德安單據的一致作法（不要把公司別、建立時間放最前面）。

### 5. 一致性
此排法與既有德安 ERP 單據 header 慣例一致，跨單據掃描體驗統一；使用者從採購單、收貨單切到成本調整單時，視線落點不需重新適應。

## 撰寫備註（供設計文件落地時對齊）
- 「單號」唯讀（用 `readonly`，非 `disabled`）；新單顯示「新單」。
- 必填欄位 label 後加紅色 `*`。
- 「公司別／部門」用既有單據術語（組織維度），不寫成「機構／單位」。
- 欄位命名沿用該模組既有規格用語；若規格未定「調整類型／調整標的」確切字樣，撰寫前與 PM 確認既有用詞，勿自創。
