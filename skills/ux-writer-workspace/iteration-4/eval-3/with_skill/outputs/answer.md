# 收款作業 header 的公司別該放哪？

## 結論先講

**不要**比照進銷存單據把公司別放在 header 末欄。收款作業屬於**財務（出納）家族**，用的是「雙列模型」，公司別應放在**第二列（後台／稅務帶入列）靠前位置**——以收款作業而言，緊接在**貸方會計科目之後**。

把財務單據的公司別壓到 header 最末尾，是已被 PM 糾正過的典型反例（照搬進銷存規則所致），務必避免。

---

## 為什麼進銷存和財務不一樣？

兩個模組家族用兩套不同的 header 排序模型，公司別落點本來就不同：

| 面向 | 進銷存（三區模型） | 財務（雙列模型） |
|---|---|---|
| 結構 | 單段為主（識別 → 決策 → 隔離）；少數拆「基本資訊＋地點資訊」 | 固定雙列（業務列／後台列） |
| **公司別落點** | 單段設計 → 排**末欄**；拆段時 → 領銜地點資訊段首位 | **後台列靠前**（列首或科目之後） |
| 經辦人欄 | 有，排日期前 | 多半無此欄 |

進銷存的「末欄」邏輯，是因為它的 header 是單一序列，公司別屬於最後的「隔離／後台區」、不擋前面的決策動線，所以落在序列末端。

財務不是單一序列，而是固定兩列：第一列放業務核心、第二列放後台／稅務帶入欄。公司別屬於「後台帶入」性質，因此進到第二列，並且不必排到列尾——它在後台列裡是靠前的。兩套模型的共通精神都是「公司別屬隔離／自動帶入、不擋決策動線」，只是落點隨結構不同。

---

## 收款作業 header 正確排法

**第一列（業務核心）：**

```
收款單號 → 收款日期 → 帳務所屬 → 收款類型 → 日記帳
```

- 收款單號第 1 格、唯讀（草稿階段顯「/」，取號後帶入）。
- 財務單據多半**沒有經辦欄**，不要為了對齊進銷存硬塞一個「經辦人」欄進去。

**第二列（後台／稅務帶入，皆唯讀或自動帶入）：**

```
貸方會計科目 → 公司別 → 部門 → 貸方傳票摘要
```

- **公司別緊接在貸方會計科目之後**，不是列首、也不是 header 最末尾。
- 部門選定後帶入稅務公司；這些自動帶入欄集中在後段，不擋第一列的輸入動線。

---

## 一句話回答你的提問

> 公司別不放末欄。收款作業是財務雙列模型，公司別放在 header **第二列、貸方會計科目之後**——靠前的後台帶入位置，而不是像進銷存那樣壓到整張 header 的最末欄。
