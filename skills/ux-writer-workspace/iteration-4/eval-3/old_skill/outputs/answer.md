# 財務單據（收款作業）的「公司別」該放哪？

## 結論

**是的，放在 header 的最末欄。** 但這不是「跟進銷存學」的特例——而是**德安 ERP 全單據共用的掃描順序**，財務單據（含收款作業）一體適用，跟進銷存單據遵循的是同一條規則。

## 為什麼放最末：使用者的單據掃描心智

德安 ERP 使用者（會計、出納、倉管、採購、業務）整天在處理單據，拿到一張單時視線與決策順序是固定的：

> **單號（這是哪張）→ 決策區（對象 → 類型 → 經辦 → 日期）→ 隔離帶入（公司別等組織維度）**

`公司別` 屬於最後一段的「隔離帶入」維度，原因有三：

1. **它不是讀單時要判斷的決策資訊**。出納看一張收款單，先確認「這是哪張單（單號）」，再確認「跟誰收、收什麼、誰經辦、哪天（決策區）」。公司別通常已由登入情境 / 帳套決定，是資料隔離用的歸屬欄，不是使用者每次都要重新判讀的決策點——所以放在視線最後，不佔據前段注意力。

2. **跨單據一致**。header 欄序對齊使用者腦中的掃描順序，他才不用在不同單據間回頭找。把公司別固定在末位，財務、進銷存、人事的單據才能「同一個位置放同一類資訊」，降低跨模組的認知負擔。

3. **避免喧賓奪主**。若把公司別、建立時間這類組織 / 系統欄位放最前面，會把真正要判斷的單號與對象擠到後面，違反掃描順序（反例：摘要寫「XX 公司｜2026/06/08｜收款單…」就把公司別錯放到最前）。

## 收款作業（財務/出納）的 header 欄序建議

套用上述順序，收款單 header 由前到後大致為：

1. **單號**（這是哪張）
2. **決策區**：
   - 對象：客戶 / 付款方
   - 類型：收款方式 / 收款類別
   - 經辦：經辦人
   - 日期：收款日期
3. **公司別**（最末，隔離帶入維度）

> 出納的在意點是「這筆錢跟誰收、收了沒、對不對得起帳」，前段就要讓他一眼掃完；公司別是歸屬資訊，殿後即可。

## 一句話回覆

公司別放最末欄是對的——這不是進銷存的專屬排法，而是德安 ERP 單據共通的「單號 → 決策區 → 公司別」掃描順序，收款作業這類財務單據同樣照此排，公司別固定收在 header 最後。
