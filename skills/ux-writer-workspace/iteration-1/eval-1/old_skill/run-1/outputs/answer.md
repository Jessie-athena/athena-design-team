# 費用請款單列表頁文案

> 套用 UX Writer 規範：Clear / Concise / Useful / Human；繁中優先、技術術語保留英文、中英之間留空格、阿拉伯數字、全形中文標點。

---

## 1. 空狀態 — 還沒有任何單據

**情境**：列表完全沒有資料（非篩選造成）。Tone：鼓勵起步。

```
還沒有任何費用請款單

建立第一張，開始送出你的費用。

[建立請款單]
```

- 主訊息：現況描述（還沒有任何資料）
- 副訊息：鼓勵 + 說明下一步
- CTA：動詞 + 對象（建立請款單）

---

## 2. 空狀態 — 套用篩選後查無結果

**情境**：有資料，但目前篩選條件查不到。Tone：鼓勵起步，引導調整條件。

```
沒有符合條件的單據

調整或清除篩選條件再試一次。

[清除篩選]
```

- 與「無任何資料」明確區分：強調是「條件」造成，不是真的沒單據
- CTA：清除篩選（讓使用者一鍵回到完整列表）

---

## 3. 成功提示 — 一次刪除 3 筆草稿

**情境**：批次刪除草稿成功。Tone：輕快肯定。以 Toast 呈現，3 秒自動消失。

```
已刪除 3 筆草稿
```

- 簡潔肯定，明確回報數量與對象（3 筆草稿）
- 數字 + 空格 + 單位（3 筆）
- 只刪草稿才可物理刪除，文案點明「草稿」對齊實際行為

---

## 4. 錯誤訊息 — 批次刪除含已被引用的單據

**情境**：批次刪除時，部分單據已被其他單據引用而無法刪除。Tone：明確但不責備，給出下一步。

句型：[發生什麼] + [為什麼] + [怎麼辦]

```
部分單據無法刪除

有 1 筆已被其他單據引用，無法刪除；其餘 2 筆草稿已刪除。
請先解除引用關係，再刪除該筆單據。

[知道了]
```

- 發生什麼：部分單據無法刪除
- 為什麼：已被其他單據引用
- 怎麼辦：先解除引用關係再刪除
- 同時回報「成功的部分」（其餘 2 筆已刪除），避免使用者誤以為整批失敗

> 數量寫法說明：實際數字由系統帶入（如「有 N 筆已被引用、其餘 M 筆已刪除」）。此處以 1 筆被引用、2 筆成功為例。
