# 費用請款單 — 列表頁文案

> 套用德安 ERP 文案慣例：空狀態 =「現況描述 +〔下一步 CTA〕」、Toast =「已[動作] N 筆」、錯誤 =「無法[動作]：[原因]」、括號分工〔可點動作〕／『引用元素』／「引述訊息」。

---

## 1. 空狀態 — 尚無任何單據

平實引導使用者建立第一筆。

```
尚無費用請款單，〔新增〕第一筆
```

- icon：`inbox`
- inline CTA `〔新增〕` 對應工具列主操作

---

## 2. 空狀態 — 套用篩選後查無結果

與「尚無單據」區分：此處是有資料、但篩選條件沒有命中，下一步是放寬或清除條件。

```
無符合條件的資料，請調整篩選條件或〔清除篩選〕
```

- icon：`inbox`
- inline CTA `〔清除篩選〕` 對應搜尋區清除動作

---

## 3. 成功提示 — 一次刪除 3 筆草稿

批次帶數量，用標準 Toast 句型；`N` 為執行期帶入。

```
已刪除 N 筆草稿
```

- 情境帶入：已刪除 3 筆草稿
- Toast kind：success，3 秒自動消失

---

## 4. 錯誤訊息 — 批次刪除含被引用單據

用「無法[動作]：[原因]」句型；原因要具體、可行動。提供兩個層級：

**主訊息（部分被擋）**

```
無法刪除：N 筆已被其他單據引用
```

- 情境帶入：無法刪除：1 筆已被其他單據引用
- 「引用」為標準術語（被其他單據參照，故不可刪），勿用「使用中／關聯」

**全部被擋（無任何一筆可刪時）**

```
無法刪除：選取項目皆已被引用
```

> 說明：若採「可刪的先刪、被引用的略過」流程，建議搭配混合結果 Toast：
> 「已刪除 N 筆，M 筆因已被引用而略過」（success/warning 視主結果而定）。
