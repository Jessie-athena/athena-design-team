# 採購退貨單 — 作廢相關文案

依 UX Writer 原則撰寫：Clear（清楚）、Concise（簡潔）、Useful（有用）、Human（人性）。
繁中優先、技術術語保留英文、中英之間留空格。

---

## (1) 作廢確認對話框（破壞性動作）

**Pattern：** `[動作描述]？ + [後果說明] + [CTA]`
**Tone：** 嚴肅清楚（破壞性動作）

| 元素 | 文案 |
|------|------|
| 標題 | 作廢這張採購退貨單？ |
| 說明 | 作廢後這張單將無法再編輯或使用，且無法復原。 |
| 主按鈕（確認） | 作廢 |
| 次按鈕（取消） | 取消 |

**完整呈現：**

```
作廢這張採購退貨單？

作廢後這張單將無法再編輯或使用，且無法復原。

[ 取消 ]  [ 作廢 ]
```

> 註：主按鈕用「作廢」明示破壞性動作（動詞），不寫模糊的「確定」；按鈕順序遵循「取消在左、危險動作在右」並以紅色 danger 樣式呈現。

## (2) 已產生傳票、不允許作廢的錯誤訊息

**Pattern：** `[發生什麼] + [為什麼] + [怎麼辦]`
**Tone：** 明確但不責備

| 元素 | 文案 |
|------|------|
| 標題 | 無法作廢 |
| 說明 | 這張單已產生傳票，無法直接作廢。請先沖銷或刪除對應的傳票，再回來作廢。 |
| 按鈕 | 知道了 |

**完整呈現：**

```
無法作廢

這張單已產生傳票，無法直接作廢。
請先沖銷或刪除對應的傳票，再回來作廢。

[ 知道了 ]
```

> 註：訊息點明原因（已產生傳票）並給出明確下一步（先處理傳票），符合「Useful — 告訴使用者接下來怎麼辦」原則；語氣陳述事實、不責備使用者。「傳票」為本系統既有業務術語，沿用既有命名以維持一致性。
