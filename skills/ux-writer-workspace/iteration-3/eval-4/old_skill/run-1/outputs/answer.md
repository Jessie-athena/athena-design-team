# 重印發票 確認彈窗文案

**情境**：餐飲 iPad POS 結帳畫面，店員點「重印發票」。屬決策性、強阻斷彈窗（會實際觸發列印動作），須用動作導向按鈕。套用 §5 餐飲（FBM / iPad POS）慣例：問句結構、動詞在右／返向在左、具體動詞。

## 彈窗文字

```
是否重印發票？
```

（若 PM 需要補一行說明，可加：「將重新列印目前帳單的發票。」——預設保持單行，POS 現場以最短為先。）

## 兩個按鈕

| 位置 | 按鈕文字 | 角色 |
|------|----------|------|
| 左 | 取消 | 返向操作 |
| 右 | 重印 | 正向操作（具體動詞） |

## 說明

- **句式**：採 POS 問句結構 `是否 + 動詞 + 受詞？`，店員一眼判讀，不需思考。
- **按鈕方向**：正向操作（動詞）在右、返向操作（取消）在左，符合 POS 現場觸控習慣。
- **動詞具體**：右鍵用「重印」而非「確認／確定／OK」等中性詞，動作與彈窗標題一致，避免誤觸。
- **無 emoji、事務性語氣**，符合 B2B 工具基調。
