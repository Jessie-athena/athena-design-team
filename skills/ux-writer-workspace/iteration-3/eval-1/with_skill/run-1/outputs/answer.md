# 費用請款單 — 列表頁文案

> 讀者：會計／財務。情境：ERP 單據導向列表，狀態機為草稿／已提交／已核准／已作廢。
> 套用 ERP 慣例：空狀態 `標題＋描述＋CTA`、Toast `已[動作] N 筆`、阻擋 `無法[動作]：[原因]`、括號 `〔〕`句中可點動作／`『』`引用 UI 元素／`「」`引述訊息。

---

## 1. 尚無任何單據的空狀態（首次進入、完全沒資料）

- **標題**：尚未建立任何費用請款單
- **描述**：建立第一張費用請款單，送出請款並追蹤核准與傳票狀態。
- **CTA（按鈕）**：新增請款單

---

## 2. 套用篩選後查無結果的空狀態

- **標題**：找不到符合條件的費用請款單
- **描述**：目前的篩選條件沒有符合的單據，請調整篩選條件或〔清除篩選〕。
- **CTA（按鈕）**：清除篩選

> 與第 1 段區隔：本段是「有資料但被篩掉」，CTA 引導放寬條件而非建立新單；句中以 `〔清除篩選〕` 提供可點動作。

---

## 3. 批次刪除 3 筆草稿成功的提示（Toast）

```
已刪除 3 筆草稿
```

> 低阻斷、自動消失、無按鈕。數量用阿拉伯數字＋空格＋單位；明確標示「草稿」呼應只有草稿可物理刪除的可逆心智。

---

## 4. 批次刪除時部分單據已被引用、不可刪的錯誤訊息

情境：一次選取多筆，其中有單據已被其他單據引用而無法刪除。屬驗證／阻擋類，用事務性句型並交代「哪些成功、哪些被擋、為什麼、下一步」。

**訊息（通知型彈窗）**

- **標題**：部分單據無法刪除
- **內文**：已刪除 2 筆草稿；其餘 1 筆已被其他單據引用，無法刪除。如需移除，請先解除引用該單據的來源單。
- **按鈕**：知道了

**全部都被引用、無一可刪時**

```
無法刪除：選取項目皆已被其他單據引用
```

> 「引用」沿用 ERP 既有術語（不用「使用中／關聯」）；點出會計懂的因果——這張被別的單用到了，故不可刪，並指向「先解除引用的來源單」的下一步。本則只是告知刪除結果、不需使用者再決策，按鈕用「知道了」（非「確認／關閉」）。
