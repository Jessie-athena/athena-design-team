# 費用請款單 — 列表頁文案

> 產品線：ERP（財務）。套用 ERP 單據慣例：狀態機詞彙、`〔〕`／`『』`／`「」` 三種括號、`無法[動作]：[原因]` 阻擋句、`已[動作] N 筆` Toast。

---

## (1) 空狀態：尚未建立任何單據

- **標題**：尚未建立任何費用請款單
- **描述**：建立第一張費用請款單來申請款項並追蹤核准進度。
- **CTA**：新增費用請款單

> 元件：Empty State，套用 `inbox` icon，事務性、無 emoji。

---

## (2) 空狀態：套用篩選後查無結果

- **標題**：查無符合條件的費用請款單
- **描述**：目前的篩選條件沒有對應的單據，請調整條件或〔清除篩選〕後再試。

> 此為「查無結果」而非「尚未建立」，故不放新增 CTA；下一步是調整或清除篩選。`〔清除篩選〕` 為句中可點擊動作。

---

## (3) Toast：批次刪除 3 筆草稿成功

```
已刪除 3 筆草稿
```

> 元件：Toast（low-blocking、自動消失、無按鈕）。套用 `已[動作] N 筆` 句型，數量用阿拉伯數字。

---

## (4) 錯誤訊息：批次刪除時有單據被引用、不可刪

驗證／阻擋類錯誤（事務性），`無法[動作]：[原因]` 句型。批次情境須分清「全部被擋」與「部分被擋」兩種結果：

**情境 A — 選取項目中部分已被引用（其餘草稿可刪）**

```
無法刪除 N 筆：已被其他單據引用
其餘 M 筆可刪除，是否繼續？        [取消] [刪除可刪項目]
```

**情境 B — 選取項目全部已被引用（無可刪項目）**

```
無法刪除：選取項目皆已被其他單據引用
```

> 「引用」為 ERP 單據術語（被其他單據參照故不可刪），不用「使用中／關聯」。原因具體可行動，不丟技術碼、不責備使用者。N／M 為阿拉伯數字。
