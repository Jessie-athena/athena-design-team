# CRS 預約失敗訊息 — 多語系改寫

> 產品線：飯店 CRS（訂房中心）｜讀者：訂房人員 / 櫃台
> 訊息類型：**驗證／阻擋類**（庫存/房況衝突是可預期的業務阻擋）→ 句型 `無法[動作]：[原因]` + 下一步
> 詞彙依據：personas-mental-models.md CRS 已識別用語（房型、訂房、候補、住房日期）；其餘現場詞彙若 PM 另有既有用語，以 PM 為準。

---

## 1. 原句的多語系破版風險

原句：`預約失敗！因為 {hotel_name} 的 {room_type} 有庫存衝突，請調整時間或日期。`

| 風險 | 說明 | 對應規範 |
|---|---|---|
| **一句兩變數** | `{hotel_name}` 與 `{room_type}` 同句，各語言語序不同（如英文、越南文的修飾語位置與中文相反），翻譯時兩個變數會互相卡位、易語意錯置。 | i18n §「一句一變數」 |
| **句中變數** | 變數埋在句子中段（「因為 X 的 Y 有…」），各語系難對齊，且變數值長度不一（飯店名/房型名長短差很多）會撐爆單行、破版。 | i18n §「避免句中變數，改 `Label: Value`」 |
| **驚嘆號 + 口語因果** | 「預約失敗！」「因為…」偏消費級語氣，且未直述被擋原因；B2B 阻擋訊息應事務性。 | §4 驗證/阻擋類句型、Voice & Tone |
| **「庫存衝突」用詞** | 「庫存」是進銷存/倉管詞；訂房情境讀者心智是「房況 / 房型已被預訂」，非「庫存」。 | §2 寫到使用者心智模型 |
| **「時間或日期」模糊** | CRS 衝突可行解通常是改住房日期或改房型；「時間」在訂房語境不精確。 | §3 清晰直接、行動導向 |

**結構改寫方向**：主訊息不帶變數（固定句，翻譯零破版風險）；把 `hotel_name` / `room_type` / 衝突日期改成訊息下方的 `Label: Value` 明細列，每個變數獨立一行，長短各自伸縮、不互相卡位。

## 2. 改寫後結構（建議呈現）

主訊息（固定、無變數）+ 明細區（每變數一行 `Label: Value`）+ 下一步行動。

```
無法完成訂房：該房型於所選住房日期已無空房

  飯店：{hotel_name}
  房型：{room_type}
  住房日期：{check_in_date} – {check_out_date}

請更換房型或調整住房日期，或將此筆轉為候補。
```

> 「轉為候補」呼應 CRS 心智模型（候補順位是訂房人員處理衝突的既有手段）；若該模組目前無候補功能，移除此句尾即可。

### 繁體中文

- **主訊息**：`無法完成訂房：該房型於所選住房日期已無空房`
- **明細**：
  - `飯店：{hotel_name}`
  - `房型：{room_type}`
  - `住房日期：{check_in_date} – {check_out_date}`
- **下一步**：`請更換房型或調整住房日期，或將此筆轉為候補。`

### English

- **Main**：`Booking failed: No availability for this room type on the selected dates`
- **Details**：
  - `Hotel: {hotel_name}`
  - `Room type: {room_type}`
  - `Stay dates: {check_in_date} – {check_out_date}`
- **Next step**：`Change the room type or adjust the stay dates, or add this booking to the waitlist.`

> 英文較長，明細採 `Label: Value` 獨立行可避免按鈕/單行表頭破版；日期格式依市場在地化（越南 DD/MM/YYYY、台灣 YYYY/MM/DD），見 Frameworks.md。

## 3. 補充：『入住日期』必填未填錯誤訊息

類型同屬**驗證／阻擋類**，套必填檢查模板 `請輸入『{FieldName}』`（Terminology.md §必填檢查）。
欄位名沿用 CRS 既有用語「住房日期」；若該畫面 label 實際顯示為「入住日期」，則文案跟隨畫面 label 一致（避免跨畫面命名不一）。此處依你提供的「入住日期」措辭。

### 繁體中文

`請選擇入住日期`

> 入住日期為日期選擇器（DatePicker），動詞用「選擇」較「輸入」貼合操作；若為手動輸入欄位則改「請輸入入住日期」。

### English

`Please select the check-in date`
