# 費用請款單｜列表頁文案

## (1) 空狀態：尚無任何單據

```
標題：尚未建立任何費用請款單
描述：建立第一筆費用請款單，向公司申請費用核銷。
CTA：新增費用請款單
```

- 套用空狀態句型「標題（狀態）＋描述（好處/原因）＋ CTA（引導開始）」，事務性、無 emoji。
- CTA 為動詞＋對象，與工具列主操作用語一致。

---

## (2) 空狀態：套用篩選後查無結果

```
標題：查無符合條件的費用請款單
描述：目前的篩選條件下沒有資料，請調整條件或〔清除篩選〕。
```

- 與「尚無任何單據」區隔：此處是「有資料但被篩選擋掉」，不引導新增，而是引導調整查詢。
- 句中可點擊動作用 `〔清除篩選〕`（inline CTA 慣例），「清除篩選」沿用既有動作用語。

---

## (3) Toast：批次刪除 3 筆草稿成功

```
已刪除 3 筆草稿
```

- 操作結果用 Toast（低阻斷、自動消失、無按鈕）。
- 套用 `已[動作] N 筆` 批次句型；阿拉伯數字、數字與單位間留空格。
- 標明刪除對象為「草稿」，與狀態機詞彙一致（只有草稿可物理刪除）。

---

## (4) 錯誤訊息：批次刪除時含已被引用的單據

屬驗證／阻擋類錯誤（可預期的業務阻擋），用事務性句型 `無法[動作]：[原因]`，不責備、不丟技術碼。

單筆受阻（指明是哪一張單）：

```
無法刪除『{單號}』：已被其他單據引用
```

批次情境（部分成功、部分受阻）— 以 Toast 回報結果，並列出受阻單號：

```
已刪除 2 筆草稿；1 筆無法刪除：已被其他單據引用（{單號}）
```

批次全部受阻：

```
無法刪除：選取項目皆已被其他單據引用
```

- 「引用」為單據領域術語（被其他單據參照故不可刪），不用「使用中／關聯」。
- 被引用的單據以 `『{單號}』` 引用 UI 動態值；訊息變數採 `Label: Value`／一句一變數，預留多語系翻譯空間。
