# 費用請款單 — 列表頁文案

## (1) 空狀態：尚無任何單據

```
尚無費用請款單，〔新增〕第一筆
```

- 套用 Empty State pattern：`[現況描述] + [下一步 inline CTA]`，事務性、無 emoji。
- 〔新增〕為句中可點擊動作（inline CTA），用 `〔〕` 括號。

---

## (2) 空狀態：套用篩選後查無結果

```
無符合條件的資料，請調整篩選條件或〔清除篩選〕
```

- 與「尚無單據」區分：此處是有篩選但查無結果，給的下一步是放寬條件，而非新增。
- 「篩選」採單據領域術語（不用「過濾器／filter」）；〔清除篩選〕為 inline CTA。

---

## (3) Toast：成功刪除 3 筆草稿

```
已刪除 3 筆草稿
```

- 套用操作結果 Toast pattern：`已[動作] N 筆`，批次帶數量。
- 「草稿」為標準狀態機顯示文字。

---

## (4) 錯誤訊息：批次刪除含被引用的單據

主訊息（套用 `無法[動作]：[原因]` 句型）：

```
無法刪除：部分單據已被其他單據引用
```

可點擊查看明細與可成功刪除的部分時，補一行帶數量的說明：

```
已被引用的單據不可刪除，其餘 N 筆草稿仍可刪除，是否繼續？  〔取消〕〔刪除其餘草稿〕
```

- 「引用」採單據領域術語（被其他單據參照故不可刪，不用「使用中／關聯」）。
- 「草稿」為標準狀態機字；數量以 `N` 表示執行期帶入。
- 若採全部阻擋（無任何可刪）情境，主訊息改為：`無法刪除：選取項目皆已被引用`。
