# 採購退貨單 — 表單頁文案

依德安 ERP 文案慣例撰寫（破壞性確認句型、`無法[動作]：[原因]` 錯誤句型、狀態機詞彙、`〔〕/『』/「」` 括號慣例）。

---

## (1) 按下「作廢」的確認對話框

**標題**

```
作廢此單？
```

**說明**

```
作廢後該單明細與後續傳票連動將無法復原，是否繼續？
```

**按鈕**

```
[取消]   [作廢]
```

> 套用要點
> - 破壞性確認句型：`[後果說明]，是否繼續？`，CTA 用明確動詞「作廢」（非「確定」）。
> - 動作詞用標準狀態機字「作廢」（voided 分支）。
> - 「傳票」為單據領域術語（不用「分錄／憑證」）。

---

## (2) 已產生傳票、不允許作廢時的錯誤訊息

```
無法作廢：本單已產生傳票，請先沖銷傳票後再作廢
```

> 套用要點
> - 錯誤句型：`無法[動作]：[原因]`，冒號分隔，原因具體且可行動。
> - 「已產生傳票」沿用 chip 既有措辭（由 `move_id` 判斷，非獨立狀態）。
> - 給出下一步：先「沖銷」傳票（依模組既有用字），再作廢。

### 替代版本（若該模組退貨單不開放使用者自行沖銷傳票）

```
無法作廢：本單已產生傳票，請改用沖銷流程處理
```

> 當作廢不是正確路徑、應走沖銷時使用；避免引導使用者去點不存在的動作。
