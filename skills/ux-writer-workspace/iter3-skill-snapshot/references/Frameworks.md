# 聲音、語調與格式框架

> SKILL.md 的「Voice & Tone」「i18n 核心規範」需要更細的語調策略或各語系格式時，查閱本檔。

## 品牌聲音 (Voice)
Voice 是固定不變的品牌個性：
- **專業但不冰冷**：以專業為基底，平易近人，不官腔、不命令。
- **清晰直接**：降低理解成本，少廢話。
- **支持性與解決導向**：提供可行解法，減少錯誤焦慮。

## 情境語調矩陣 (Tone Matrix)
Tone 依使用者當下狀態調整。德安是 B2B 專業工具，範例採事務性專業口吻——肯定但不過度熱情、不裝可愛、不用 emoji。

| 情境 | 語調策略 | 規範建議 | 範例 |
| :--- | :--- | :--- | :--- |
| **入門/介紹** | 親切、引導 | 引導完成設定，正向但不浮誇 | 歡迎使用，先從建立第一筆資料開始。 |
| **任務完成** | 簡潔肯定 | 簡短肯定操作，不過度情緒化 | 設定已更新。／已核准。 |
| **指引/幫助** | 清晰、耐心 | 分步式敘述，避免抽象說明 | 請選擇資料來源，再點擊「建立」。 |
| **通知** | 中立、資訊性 | 聚焦資訊傳達，不製造緊張感 | 您的訂閱將於 3 天後續訂。 |
| **錯誤（系統/預期外）** | 同理、安撫 | 提供解法，嚴禁責備 | 系統暫時無法處理，請稍後再試。 |
| **錯誤（驗證/阻擋）** | 明確、事務性 | 直述被擋原因與下一步 | 無法刪除：已被歷史單據引用。 |

## 國際化格式規範 (i18n Formatting)

### 1. 日期格式 (Date)
| 地區 | 格式範例 | 規範 |
| :--- | :--- | :--- |
| **台灣** | 2025/01/01 週一 | 使用 `/` 分割，MM/DD 補零 |
| **日本** | 2025/01/01 月曜日 | 排列順序依地制宜 |
| **越南** | 01/01/2025 Thứ Hai | 視為 B2B 系統核心規範（DD/MM/YYYY） |
| **北美** | Mon, 01/01/2025 | 需支援 Syncfusion 標準格式 |
| **中國** | 2025-01-01 周一 | 使用 `-` 分割 |

### 2. 貨幣格式 (Currency)
- **原則**：金額須**靠右對齊**以便比對位數。
- **範例**：台灣 (NT$ 1,000)、日本 (¥1,000)、越南 (1.000 ₫)。
- 注意小數與千分位符號各地不同（越南以 `.` 為千分位）。

### 3. 姓名欄位結構
- **台灣/日本**：姓 / 名（姓在前）。
- **北美**：First / Last Name。
- **越南**：餐飲系統不強制三段姓名（追求效率）；身份驗證系統則需完整姓名。

## 專業術語使用前提
當主要使用者為產業從業人員時，優先使用業界通用術語，但須符合：
1. **業界通用**：非公司內部黑話。
2. **語義唯一**：同一概念僅用一個詞彙。
3. **一致性**：建立報表 vs 新增報表，應統一一個動詞。
4. **性別中立**：用「使用者」「客戶」替代「他／她」，降低文化誤解與歧視風險。
